Dog Adoption Analysis Project

Overview
This project analyzes factors that influences both dog adoptions and returns. The data set contains information on individualized dog temperaments/behaviors as well as information on their adopter. I used this information to determine my findings.

Dataset
Source: Kaggle - Dog_adoption_master :
https://www.kaggle.com/datasets/sergionefedov/dog-adoption-success-does-the-match-last

Tools Used:
Python
Pandas
NumPy
Matplotlib
Jupyter Notebook.
